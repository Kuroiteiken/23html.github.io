Echoes Beneath development history

Changelog

Player-facing releases, gameplay improvements, content additions, and fixes.

This fork is now called Echoes Beneath. It began as a fork of the upstream Proto23 game and keeps its save format, its repository name, and its stored preferences, so existing saves and language settings continue to work.

← Back to game

Early alpha — systems and save compatibility may change.

Release

v476

v475 → v476 2026/08/17
  • A damaged save is now checked before anything is restored. Previously a shifted or truncated save could load as the wrong data; it is now backed up untouched and reported instead
  • Every creature now has a rank, so the bestiary's rank column reads properly instead of showing '???' for almost half the roster
  • Hovering a bestiary entry now shows what the encyclopedia says about that creature; the book previously listed only a name, a rank, and a kill count
  • Lowered the message log limit ceiling from 120 to 50; a longer log cost more than it gave back
Release

v475

v474 → v475 2026/08/16
  • The Agility mastery now actually does something. It granted nothing when levelled and described Strength's bonuses instead of its own
  • The nervous man at the market stalls responds when you press him or give him space, rather than repeating one line
  • The last English text in the game now follows the selected language: quest objectives and their locations, furniture and title effects, action descriptions, and the mastery panel
  • Corrected menu choices that read as instructions not to do the thing. In Turkish "Satın alma" means both "purchasing" and "do not buy"; the shop, the reward claim, and six other choices were written that way
  • Switched eight choice labels from the formal plural to the singular the rest of the game uses
  • Fixed the dojo training areas sharing an identifier, which gave one of them no identity of its own
  • Fixed the completed-jobs counter never advancing, and fixed the guard duty timer continuing to run after the shift ended
  • Completing the wolf hunt now grants the Wolf Slayer title, which existed but could never be earned
  • Guard duty can be left early. The post had no exit at all, so the only way out was to wait until 8PM
  • The game no longer stops while its tab is in the background. Time, combat, and book reading now follow the clock and catch up when you come back, instead of freezing as soon as the browser throttled the page
  • Reserved room below the inventory list for the sort bar, which was covering the last rows of a long inventory
  • Renamed the student skill books after the masteries they teach, so a book and its skill panel entry finally agree
  • Replaced the cramped "DP" durability readout with a labelled gauge. The number now sits beside the bar instead of on top of it, where it was unreadable at the yellow and green levels
  • Corrected the shady kid's name in Turkish, which read as "shaded" rather than "suspicious"
  • Fixed the inventory sort bar overlapping the item list when the inventory was long
  • Autosave now runs every 15 seconds instead of 30, and Settings has an interval you can change; the new interval takes effect immediately. Autosave is also remembered on its own, and its checkbox no longer disagrees with whether it is actually running
  • The message log now survives a reload. It keeps as many messages as the message log limit allows, which can now be raised to 120, and clearing the log clears the kept history with it
  • Returning to the game from the changelog now closes that tab rather than opening a second copy of the game in it
  • Gave the settings rows room to breathe instead of stacking their labels and controls against each other
  • The background theme is now remembered on its own, like the language is. It used to live only inside the save, so the choice was lost unless the game happened to be saved afterwards
  • Translated the skill panel's remaining English: every skill description, mastery name, and perk label now follows the selected language, and the stat abbreviations in the top bar match them
  • Showed Luck alongside the critical chance readout; it could be raised by titles and skills but was never displayed anywhere
  • Moved the kill counter to the bottom-left of the item tooltip so it no longer sits under the description
  • Fixed the "destroy gradients" setting not restoring its state after a save was loaded, and gave it and the autosave checkbox a control that matches the rest of the interface
  • Corrected more than a hundred interface positions and sizes that the browser was silently discarding, which is what left the destroy confirmation invisible, pushed the shop quantity buttons on top of the item name, and buried the durability numbers inside their own bar
  • Repaired the confirmations shown before destroying or disassembling equipped gear, which could render off-screen or invisibly, and gave them the same keyboard-accessible dialog used for save deletion
  • Fixed high resistance skills healing instead of protecting: food poisoning restored satiation and corruption restored health once those resistances passed level 20
  • Fixed quest tracking removing the wrong background task when a quest was completed or a save was loaded
  • A save that cannot be read is kept as a backup and reported instead of being replaced silently by a new game
  • Imported saves are now stored properly instead of being lost on the next reload
  • Damaged saves no longer restore missing statistics as blank values
  • Fixed the "pause next battle" label showing the wrong state after loading a save
  • Dying no longer punishes the Death skill; a higher skill now preserves more satiation instead of draining it completely
  • Fixed explored area sizes shifting onto the wrong areas after loading, which lost hunting progress
  • Fixed the agility multiplier being reset every time the game was saved and loaded
  • This fork is now called Echoes Beneath. It began as a fork of the upstream Proto23 game and keeps its save format, its repository name, and its stored preferences, so existing saves and language settings continue to work
